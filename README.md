# PixelProve

A cutting-edge decentralized platform leveraging blockchain technology to empower photographers in minting, trading, and protecting their digital artworks as Non-Fungible Tokens (NFTs) on the Stacks blockchain.

## Key Features
- 🖼️ Advanced NFT Minting for Photographs
  - Comprehensive metadata capture (camera settings, GPS location, timestamp)
  - Cryptographic proof of original creation
  - Immutable ownership records

- 🔐 Secure Ownership and Provenance
  - Transparent transfer of photograph ownership
  - Permanent blockchain-verified authenticity
  - Detailed ownership history tracking

- 💰 Creator-Centric Monetization
  - Dynamic royalty mechanisms
  - Flexible sales and listing options
  - Direct creator-to-collector marketplace

- 🌐 Blockchain Benefits
  - Decentralized storage and verification
  - Smart contract-powered transactions
  - Low-cost, environmentally conscious NFT minting

## Contract Functions
- `mint-photo`: Create a new photograph NFT with full metadata
- `transfer`: Securely transfer photograph ownership
- `list-for-sale`: Set up marketplace listings
- `buy-photo`: Purchase listed photographs
- `get-photo-details`: Retrieve comprehensive photograph metadata
- `update-royalties`: Manage creator royalty percentages

## Technical Stack
- Blockchain: Stacks (Bitcoin Layer)
- Smart Contract Language: Clarity
- Development Tools: Clarinet, Hiro Wallet

## Getting Started
1. Prerequisites
   - Node.js (14+ recommended)
   - Stacks Wallet
   - Clarinet CLI

2. Setup and Installation
   ```bash
   # Clone the repository
   git clone https://github.com/yourusername/pixelprove.git
   
   # Navigate to project directory
   cd pixelprove
   
   # Install dependencies
   npm install
   
   # Run test suite
   clarinet test
   ```

3. Deployment
   - Configure your Stacks network settings
   - Deploy smart contracts
   - Connect your Hiro Wallet
